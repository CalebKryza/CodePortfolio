Description-
This is a web-based demonstration of a reinforcment algorithm applied to solve a maze. It visualizes how an AI agent learns the optimal path from start to goal through trial and error.

Features-
Maze Generation
Q-Learning Agent
Step-by-Step Visualization
Built with JavaScript, HTML, and CSS

How to Run-
clone the repository
open index.html in your browser

Controls-
Train: Starts training the agent, the blue square is the agent; they spawn at the green square (home) and try to make it towards the red square (goal) - Runs for 100 episodes, each episode is at max 100 steps long
Best Path: After training this shows the shortest path it found over its 100 episodes on how to get to the goal
Reset: Reloads the page, resetting the training

Skills Demonstrated-
Reinforcment Learning: Implemented Q-Learning algorithm
JavaScript Algorithms: State/Action managment, matrix manipulation
DOM Manipulation: Canvas Drawing, User Interface Controls, Dynamic Animation
CSS Layout and Styling: Simple, Responsive visual presentation
Debugging anf Problem Solving: Handled state syncing, agent visualization, and learning convergence
